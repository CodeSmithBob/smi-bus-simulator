Commissioning

Factory-new drives all sit on address 0. The reference discovery searches slave IDs with the compare telegram and gives each drive its own address. Every step is a real telegram, so you can follow it in the monitor.

Connect your controller to a line, start a session and let it work. The lab watches the telegrams, injects faults when you arm a check and scores the behaviour. This is an unofficial pre-check, not an SMI e.V. certification.

    The official SMI specification is only available to members of SMI Standard Motor Interface e.V. This simulator is built from public sources. Each part of the protocol carries a status, and the monitor marks telegrams that rely on provisional encodings.
